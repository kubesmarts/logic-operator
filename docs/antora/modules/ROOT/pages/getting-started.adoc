= Getting Started
:description: Deploy Logic Operator on a local KIND cluster and run your first workflow.

This guide deploys Logic Operator on a local https://kind.sigs.k8s.io[KIND] cluster and runs the hello-world sample workflow end-to-end.

== Prerequisites

* https://docs.docker.com/get-docker/[Docker] (or compatible runtime)
* https://kind.sigs.k8s.io/docs/user/quick-start/#installation[KIND] v0.20+
* https://kubernetes.io/docs/tasks/tools/[kubectl]
* https://git-scm.com[Git]
* Kubernetes {k8s-min-version}+ cluster (KIND creates one automatically)

== 1. Clone the repository

[source,bash]
----
git clone https://github.com/kubesmarts/logic-operator.git
cd logic-operator
----

== 2. Create a KIND cluster

[source,bash]
----
make kind-create
----

This creates a local Kubernetes cluster with:

* https://cert-manager.io[cert-manager] (required for admission webhooks)
* https://kubernetes.github.io/ingress-nginx[ingress-nginx] (for `*.lvh.me` routing)

== 3. Deploy the operator

[source,bash]
----
make kind-deploy
----

This builds the operator image, loads it into KIND, and applies all manifests (CRDs, RBAC, Deployments, webhooks).

[NOTE]
====
If the next step fails immediately with a webhook error, the cert-manager certificate is still being issued.
Wait for the operator pod to be ready, then retry:

[source,bash]
----
kubectl wait --namespace logic-operator-system \
  --for=condition=ready pod \
  -l control-plane=controller-manager \
  --timeout=60s
----
====

== 4. Apply the hello-world sample

[source,bash]
----
make kind-demo
----

This creates a `LogicPlatform` with the workflow gateway enabled, a `LogicFlowRuntime`, and a `LogicFlowDefinition` (the hello-world workflow) in the `default` namespace. The gateway routes to the runtime Service using `spec.runtimeRef`; no `LogicFlowService` is required.

Verify everything is ready:

[source,bash]
----
kubectl get logicplatforms,logicflowruntimes,logicflowdefinitions
----

Inspect gateway readiness and its public URL in the LogicPlatform status:

[source,bash]
----
kubectl get logicplatform logicplatform-sample -o yaml
----

== 5. Invoke the workflow

[source,bash]
----
curl -X POST http://gateway.lvh.me/v1/runtime/default/hello-world/1.0.0/sync \
  -H "Content-Type: application/json" \
  -d '{"name": "world"}'
----

The gateway returns the synchronous workflow response:

[source,json]
----
{"message": "Hi, world!"}
----

== 6. Check metrics

Start kubectl port-forward svc/hello-runtime 8080:80 in a separate terminal, then query the runner's Micrometer metrics at `/q/metrics`:

[source,bash]
----
curl http://localhost:8080/q/metrics | grep quarkus_flow_workflow
----
